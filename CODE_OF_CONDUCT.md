# Code of Conduct

ScacchiForge contributors are expected to keep the project rigorous, humane, and
useful.

## Expected behavior

- Be precise and respectful.
- Critique code, architecture, and evidence rather than people.
- Back a claim about correctness, strength, or speed with the command that shows
  it.
- Do not present a heuristic as a theorem. State the classification honestly,
  and change it when the evidence changes.
- Explain tradeoffs when rejecting or changing an idea.
- Keep discussions focused on the project and its users.
- Treat security reports with care and in private.

## Unacceptable behavior

- Harassment, threats, insults, or sustained personal attacks.
- Publishing private information without consent.
- Dismissing a security concern without investigating it.
- Derailing technical discussions with bad-faith repetition.
- Pasting code from Stockfish, from code derived from it, or from proprietary
  engines. The project is original work.

## Enforcement

Maintainers may edit, hide, lock, or remove contributions that violate these
expectations.

## Reporting

No private channel for conduct reports has been chosen yet. When there is one,
this file names it. Security reports follow [SECURITY.md](SECURITY.md).

Content that breaks GitHub's own rules can be reported to GitHub with
**Report content** in the menu of the comment, issue or pull request
([GitHub Docs](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)).
